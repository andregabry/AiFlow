Quero que desenvolvas uma aplicação desktop multiplataforma completa chamada **AiFlow**, pronta para uso real e compilável para Windows (.exe/.msi) e macOS (.app/.dmg).

O AiFlow será um orquestrador de agentes de IA para desenvolvimento de software. Ele deverá conectar GitHub, repositórios locais e diferentes provedores de IA, consumir Issues/tarefas, enviá-las ao agente selecionado, acompanhar a execução, validar a conclusão e avançar automaticamente para a tarefa seguinte.

IMPORTANTE: o projeto NÃO pode ser arquitetado especificamente para Codex.

Desde o início, AiFlow deverá ser uma plataforma MULTI-PROVIDER preparada para:

- OpenAI Codex
- Anthropic Claude / Claude Code
- Google Gemini / Gemini CLI
- futuros provedores

A arquitetura deve permitir acrescentar novos provedores sem modificar o orchestrator, GitHub integration, queue manager, UI ou regras de negócio.

- incrementar attempt.
