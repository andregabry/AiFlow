    sequence

==================================================
121. IMPLEMENTAÇÃO, NÃO MOCK
==================================================

É permitido usar mock data apenas na fase visual inicial.

Porém a funcionalidade não pode ser considerada concluída enquanto:

- Issues não vierem realmente do GitHub;
- provider status não vier realmente do adapter;
- output não vier realmente do processo;
- estado não for persistido;
- queue não controlar realmente execução;
- completion não for realmente validado.

No IMPLEMENTATION_STATUS distinguir:

UI MOCK
UI CONNECTED
BACKEND READY
INTEGRATION VALIDATED
